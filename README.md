# Практическая работа № 2. Функции, срезы и карты

Курс «Бэкенд-разработка на языке Go».

## Окружение

* Операционная система: укажите свою систему.
* Версия Go: вставьте результат команды `go version`.
* Редактор: укажите используемый редактор.

## Выполнено

Программа работает со списком статусов задач и выводит по нему статистику.

* Функция `statusLabel` — переводит код статуса (`new`, `in_progress`, `done`) в подпись на русском через `switch`; для неизвестного кода возвращает «Неизвестен».
* Функция `countStatus` — считает, сколько раз заданный статус встречается в срезе.
* Функция `findStatus` — возвращает индекс первого элемента с заданным статусом или `-1`, если такого нет.
* Функция `completionPercent` — считает процент задач со статусом `done`; для пустого среза возвращает `0`.
* В `main` создаётся срез статусов, в него добавляется элемент через `append`, выводится нумерованный список задач.
* Статистика по всем статусам собирается в карту `map[string]int`, созданную через `make`.

## Запуск программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```
go run .
```

## Проверка сборки и оформления

```
go fmt ./...
go build ./...
```

## Проверенные данные

Входные данные задаются в коде:

```go
statuses := []string{"new", "in_progress", "done", "done"}
statuses = append(statuses, "new")
```

Фактический вывод:

```
Задач всего: 5
1. Новая
2. В работе
3. Завершена
4. Завершена
5. Новая
Завершено: 2
Статистика: new=2, in_progress=1, done=2
2
Done: 40 percents
```

* `findStatus(statuses, "done")` вернул `2` — первый `done` стоит на третьей позиции (индексы с нуля).
* Процент завершения: 2 из 5 = 40%.
